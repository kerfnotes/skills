# Domain documentation

This repository uses a single-context documentation layout.

Before exploring a feature, read the root `GLOSSARY.md` and relevant `docs/adr/` records when present. If a root `GLOSSARY-MAP.md` exists later, follow it to the relevant context. Missing glossary or ADR files are not blockers and should not trigger unsolicited scaffolding.

Use existing domain vocabulary. For skill-local work, read that skill's current `SKILL.md` and relevant references as the implementation contract. Raise a real conflict with an ADR explicitly rather than silently overriding it.
