# Triage labels

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate the issue. |
| needs-info | needs-info | Waiting for required information. |
| ready-for-agent | ready-for-agent | Specified and suitable for agent implementation once blockers are resolved. |
| ready-for-human | ready-for-human | Requires human implementation. |
| wontfix | wontfix | Will not be actioned. |

Preserve unrelated labels. Existing labels with these names are reused without overwriting their descriptions or colors.
