# 有數字稿的驗收清單

對照 [原稿](with-numbers.md)，由未參與 skill 開發的 agent 從頭做出故事線、story.json、PowerPoint。只先交原稿與 SKILL.md 給製作者，驗收者再讀這份清單；不提供預寫好的簡報答案。

- [ ] 有能串起需求、證據與行動的故事線，每頁一句判斷；不是把段落逐一貼成投影片。
- [ ] 選擇約三至五張能支撐判斷的圖；月報趨勢、宣傳來源、活動偏好、同批報名歷程都是可用證據，不必為了湊圖重複同一結論。
- [ ] 月報的 300、380、450、510 件按月份排列；沒有把相關性寫成宣傳的因果成效。
- [ ] 電話的 0 留作觀察值；合作店家留空，來源列說明未提供，沒有補 0。
- [ ] 問卷回覆與完成報名分母不同；據點偏好保留原始件數，沒有將其解讀成收益或容量。
- [ ] 報名流程的人數次序正確；差額、合計如另行填入 visual，當頁 notes 或 sources.more 有可核對算式。
- [ ] 沒有自行新增預算、改善百分比或核定日期，沒有聲稱缺席原因已被證明。
- [ ] 每頁來源列註明虛構示意資料，已知的單位與期間正確；講稿在 notes。
- [ ] `node evals/check.mjs <story.json> ../../evals/kerf-clayprint/with-numbers.md`（在 skill 資料夾執行）通過；警告有逐項看圖與處置記錄。
- [ ] PowerPoint 實際開啟無修復提示，逐頁無裁切、重疊與難讀文字；記下最弱一頁修改前後的理由。
- [ ] 可編輯圖表與 SVG 的範圍說明正確；有授權的實機環境實測修改一個原生圖數值。未能操作時明記未驗，不以建檔通過代替。

驗收紀錄應包含：檔案路徑、逐頁結果、警告處置與剩餘限制。這是人工清單，不預設所有項目已完成。
