# 情境：月結只有我會，主管不放人

卡點：現職少不了你，主管不放人｜圖型：不指定（測 board.md §3 的退路）｜交付：不限

## 使用者輸入

```
我在財務部做了四年，每個月的月結報表都是我在跑，組裡只有我會。上個月新產品組開了一個財務分析職缺，我很想去，也跟新產品組的主管珮君聊過，她說：「我們很歡迎，你那邊放人就可以。」

我跟我的主管提，他說：「你現在走，月結誰跑？等明年再說。」人資說內部轉調要現任主管簽核，職缺月底就截止。

我該怎麼讓主管放人？
```

## 預期卡點與圖型

主管擋的理由是月結沒人接，不是否定使用者；簽核在他手上（人資說的），珮君的歡迎有條件。卡點是降低主管放人的代價。六種圖型裡可能用利益交集（雙方在意什麼、談不成時各自能做的）、決策圈（誰簽核）或對照表；本則只記錄，不因結果新增圖型。

## 通過條件

1. 附地圖，圖能幫使用者選第一步：看得出主管擋的理由，以及使用者能先補上的東西（例如月結有人接）。圖型不限。〔board.md §3〕
2. 主管的話照原話記，沒有改寫成「主管反對你」「主管不認同你」；對主管動機的判斷標推測。〔SKILL.md §2〕
3. 珮君「你那邊放人就可以」沒有寫成已錄取、職位已保留，或她會出面說服主管。〔SKILL.md §2 表態照原話記〕
4. 簽核照人資說的寫現任主管簽核；沒有推定處長或人資能越過主管核定，要提就標未知並給查法。〔SKILL.md §2〕
5. 第一句說出卡在哪與第一步；句中人名、事件都在輸入出現。〔SKILL.md §1〕
6. 第一步是今天就能提的請求（例如問主管要什麼條件才肯簽、提一個交接安排），沒有設「先把月結寫成手冊」「先找到接手的人」這類做完才能開口的門檻。〔SKILL.md §2 今天就能提的請求不設門檻〕
7. 不替使用者承諾沒選的付出：延後到職、調走後繼續支援月結、帶新人跑幾次月結、加班交接這類付出放「你願意才加」並寫上限或代價。〔SKILL.md §2 不替他承諾〕
8. 稿和圖沒有出現輸入沒給的數字、時長、日期（例如「兩次月結」「交接三週」寫成事實）；要用就標推測，或寫成讓使用者自選的選項。〔SKILL.md §2〕
9. 若列退路：只寫不需這位主管點頭就能做的事，或明寫目前沒有；還要主管簽核的安排不叫退路。〔SKILL.md §2 退路要獨立〕
10. 至少一條建議用一句話指回書中機制（例如《Power》表現太好，主管反而不放人）。〔SKILL.md §3〕
