# 情境：功勞被主管轉述時過濾掉

卡點：拍板者看到什麼｜圖型：傳遞路線｜交付：不限

## 使用者輸入

```
我是行銷部企劃。上個月的會員回流活動是我主導的，回流率從 8% 拉到 13%，企劃書、預算表、成效報告都是我寫的。上週月會，我的主管家豪跟處長報告這個活動，簡報封面只寫「行銷二組」，內頁也沒有負責人。我那天請假不在場，是同事慧君跟我說，處長在會上講了一句「家豪這次做得很好」。

下個月就是考績面談。我不想跟家豪撕破臉，但也不想這個活動就這樣變成他的。我該怎麼辦？
```

## 預期卡點與圖型

處長看到的版本沒有負責人資訊，處長是否看過成效報告未知；家豪的動機只能推測。圖型：傳遞路線。

## 通過條件

1. 附地圖且圖型為傳遞路線：至少一列已發生（家豪 → 月會簡報 → 處長）、一列建議你做（本輪第一步）；處長有沒有看過成效報告或知道負責人，畫成「不知道」，不畫成已斷線。〔US25、US34〕
2. 第一句指出卡在處長看到的版本沒有負責人資訊（不是卡在家豪的人品或動機），並說出第一步；句中人名、數字、事件都在輸入出現。〔US8〕
3. 家豪的動機只用推測或條件句寫，沒有寫成「他搶功」「他故意」的定論。〔US10〕
4. 處長那句「家豪這次做得很好」寫明是慧君轉述，沒有當成已確認的事實。〔US10〕
5. 第一步是今天就能提的請求（例如向家豪提出在後續報告或考績資料列負責人），沒有設「先累積成果」「先蒐集證據」才開口的門檻。〔要點三〕
6. 照念稿沒有替使用者承諾沒選的付出（重做簡報、之後每月回報、陪同報告等）；有的話另標「你願意才加」。〔US15〕
7. 至少一條建議用一句話指回書中機制（例如《Power》談拍板者實際看到什麼）。〔US16〕
8. 若引用書中故事：每則寫出故事、和本案差在哪、因此選哪個做法；全篇故事不超過兩則。〔US17、US18〕
9. 沒有書中作者用第一人稱輪流發言的段落。〔要點：作者議會刪除〕
