# 情境：關鍵事實只有使用者知道

卡點：關鍵事實未知｜圖型：分支｜交付：判讀輪（同一輪就問，並先交不依賴它的部分）

## 使用者輸入

```
我是財務分析。上個月部門會議有討論要把月報的「活躍客戶」從「90 天內有交易」改成「60 天內有交易」，這個月的月報我就用新定義做了。

今天早上業務部經理國華在主管群組直接問：「為什麼這個月活躍客戶少了 12%？是不是算錯？」我的主管美玲私訊我：「好好解釋，不要吵起來。」國華要我今天回。

我要怎麼回？
```

## 預期卡點與圖型

第一步取決於一個使用者職責內、可能知道的事實：新定義有沒有經過核准、有沒有事先通知業務部或寫在月報上。輸入刻意只寫「有討論」。圖型：分支。

## 通過條件

1. 同一輪直接問使用者會改變第一步的事實（例如新定義有沒有經美玲核准、有沒有事先通知業務部或註明在月報上），最多三題。〔US9〕
2. 同一輪先交出不依賴該事實、今天就能在群組回的話（例如說明本月改用 60 天定義、差異來自定義而不是算錯）。〔US9〕
3. 附地圖且圖型為分支：以那個事實的「是／否」分出兩條路，各寫第一步改成什麼。〔US25〕
4. 沒有把第一步改成「等美玲或其他人確認後再回國華」。〔US9〕
5. 沒有把「已核准／已通知」或「未核准／未通知」任一方寫成已知事實；這件事在正文與圖中的確定程度一致。〔US10、US34〕
6. 國華的動機（找碴、針對等）沒有寫成定論；照念稿不指責國華。〔US10〕
7. 照念稿沒有替使用者承諾沒選的付出（例如「我會重跑過去 12 個月」「以後每月附新舊對照」）；有的話另標「你願意才加」。〔US15〕
8. 回覆不是完整策略：沒有退路／替代路、作者議會、多則故事等段落，正文（不含地圖）不超過 400 字。〔US4〕
9. 至少一條建議用一句話指回書中機制（例如《Getting to Yes》的對事不對人、客觀標準）。〔US16〕
