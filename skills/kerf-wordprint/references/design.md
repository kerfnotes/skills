# Wordprint 顯示層

## 主題

輸入頁、連續逐字稿、摘要 HTML 與 PDF 統一沿用 Clayprint。紙面、文字與陶土色重點保持一致，表單按操作密度排版，文件按閱讀與列印排版。

## 色彩

唯一設計來源是相鄰 `kerf-clayprint/design/tokens.json`。預設紙面 `#FAF9F5`、正文 `#141413`、次要文字 `#5E5D59`、分隔線 `#E8E6DC`、重點 `#C2553A`、選取底 `#F5E6DE`。輸入頁直接讀 JSON，不新增 Node 或網路依賴；獨立安裝時保留相同預設值。明確指定 `CLAYPRINT_TOKENS` 時使用該設計層。

## 字體

沿用 Clayprint 的 Helvetica Neue、Segoe UI、Arial、PingFang TC、Microsoft JhengHei。螢幕正文 16px；表單說明 13px；標題使用 600 字重。PDF 使用 Clayprint 既有列印字級與版心。

## 元件

表單按鈕與輸入框使用 4px 圓角，按鈕觸控範圍至少 44px。主按鈕使用陶土色；其他按鈕使用紙面與可辨識邊框。鍵盤焦點清楚呈現，停用、上傳、錯誤及成功沿用現有狀態語意。

## 版面

單欄最大寬度 940px，桌面兩側 24px、手機 18px。表單順序為錄音來源、轉錄與摘要、選填交付、確認。逐字稿維持原 ASR chunk 的連續閱讀；摘要使用 Clayprint 原有報告結構。

## 層次

平面紙張與細分隔線，不加陰影卡片、裝飾背景或浮動品牌橫幅。需要表示選取時使用淺陶土底。

## 保留與省略

保留來源順序、引擎選擇、雲端用途揭露、失敗恢復與讀屏資料。未指定的本機模型維持 0.6B。不加入宣傳文字、通用校對警語或逐列核對模式。不為樣式修改逐字稿、時間、摘要內容或驗證規則。

## 響應式與動作

窄版按鈕與來源操作自然換行；長路徑與中英文混排不得溢出。按壓回饋沿用 1px 位移，鍵盤與減少動態效果設定不觸發位移。切換設定不加進場動畫。

## 後續修改

先改 Clayprint 設計層，再重建需要更新的產物；不要在單一頁面另造色票。表單使用自含原生 CSS 與 `--cp-*` 變數，介面別名使用 `--wp-*`。文件繼續使用 `theme-css.js`、`report.js` 與 `pdf.js`，不複製一套報告模板。只換樣式時保留原文。
