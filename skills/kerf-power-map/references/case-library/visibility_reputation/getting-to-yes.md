## Caradon相信Kuznetsov私人請求延後表決

案例編號：getting-to-yes-148。類型：書中歷史事件敘述。

**人物／組織：** Lord Caradon、Vasily Kuznetsov、United Nations Security Council

**書中情境與行動：** 1967年Caradon因信任Kuznetsov而同意延後兩天表決；對方撤回蘇聯案、改投英國案，使242號決議一致通過。

**故事：** 1967 年中東戰爭後，英國駐聯合國大使 Caradon 為安理會決議奔走，看來除了蘇聯之外已有共識。蘇聯代表 Kuznetsov 卻上門要求把表決延後兩天，Caradon 擔心對方藉機替蘇聯版本拉票，原本不想答應。Kuznetsov 只多說了一句：這是我「個人」的請求。Caradon 立刻讓步，因為他與對方共事過、敬重他，認定彼此信得過。兩天後表決，Kuznetsov 舉手支持英國案，並撤回蘇聯自己的決議，第 242 號決議因而一致通過。Caradon 事後相信，對方是回去說服了本國政府，大概也包括阿拉伯國家；這是他的回憶與推測，書中沒有進一步佐證。

**作者用它說明：** 可信賴的個人聲譽本身就是談判力量，它能讓對方接受原本會疑慮的請求。

**可比較的問題：** 長期可信關係可讓臨時調整程序被接受

**個別界線：** 來自書中轉引回憶；私下遊說對象部分為當事人推測。
