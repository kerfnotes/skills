## 棒球薪資最後最佳報價仲裁

案例編號：getting-to-yes-078。類型：書中歷史事件敘述。

**人物／組織：** Professional baseball、Arbitrator、Public employees

**書中情境與行動：** 仲裁者只能選雙方最後報價之一，促使提案趨合理並增加和解；仍可能被迫在兩個極端間選擇。

**故事：** 作者列舉「請第三者參與決定」的辦法時，提到職業棒球的球員薪資爭議。這裡用的是「最後最佳報價仲裁」：雙方各提出最後一次報價，仲裁者只能二選一，不能折衷。作者說這個制度的理論是：既然仲裁者只會選比較合理的那一份，雙方就有壓力把提案修得更合理。書中說，在棒球界，以及某些州規定公務員爭議必須採用這種仲裁的地方，看起來比傳統仲裁帶來更多和解。但沒有和解的當事人，有時會讓仲裁者面對兩個極端報價，難以抉擇。書中沒有給出研究出處、數據、年份或具體球員案例，只是概括描述。

**作者用它說明：** 用程序設計（只能選一方最後報價）促使雙方提案趨於合理，但仍有失靈的風險。

**可比較的問題：** 用程序誘因減少極端報價

**個別界線：** 書未提供研究識別與數據，不能視為普遍優越的實證結論。

**相關分類：** [客觀標準與公平程序](../standards_process/index.md)、[制度與誘因](../institutions_incentives/index.md)、[貢獻與能力評價](../performance_evaluation/index.md)

**相關名稱與說法：** last best offer arbitration、baseball、棒球、最終報價仲裁

**出處：** 第 5 章〈Insist on Using Objective Criteria〉

<a id="getting-to-yes-080"></a>
## 警察工會用鄰市薪資替立場背書

案例編號：getting-to-yes-080。類型：假設／教學示例。

**人物／組織：** Police union

**書中情境與行動：** 工會先定加薪要求再用其他城市薪資辯護，若拒聽其他基準，只會把立場鎖得更深。

**故事：** 這是作者的假設示例。警察工會先定下一個加薪幅度，再引用其他城市警察的薪資，替這個數字辯護。作者指出，這是談判中很常見的用法：多數人把先例和客觀標準當成替既定立場背書的論據，而不是共同尋找公平標準的依據。結果是，這種用法通常只會讓雙方在自己的立場裡挖得更深。書中沒有交代任何真實工會、城市或結果，也沒有對方的反應，只拿它對比「原則式談判」：真正的原則式談判者帶著準備好的標準上桌，卻仍願意被理由說服，願意聽對方提出的其他標準，或請雙方都信任的人建議哪個標準較合適。作者說，兩者差異有時很細微，但一直很重要。

**作者用它說明：** 把客觀標準只當成替立場辯護的論據，反而讓人更固守立場；真正的原則式談判要對理由保持開放。

**可比較的問題：** 區分開放檢查基準與挑選有利證據

**個別界線：** 沒有特定工會資料，屬教學示例。

**相關分類：** [客觀標準與公平程序](../standards_process/index.md)、[貢獻與能力評價](../performance_evaluation/index.md)

**相關名稱與說法：** police union、other cities、警察工會、加薪

**出處：** 第 5 章〈Insist on Using Objective Criteria〉

## Tom Griffith以可比車價拿到理賠

案例編號：getting-to-yes-081。類型：作者觀察或匿名實務敘述。

**人物／組織：** Tom Griffith、Insurance adjuster

**書中情境與行動：** Griffith拒把公司政策當估值理由，逐項比較里程與配備，最終由一萬三千六百提高到一萬八千零二十四。

**故事：** 作者的同事 Tom Griffith 停放的車被傾卸卡車撞到全毀，車有投保，賠多少要和理賠員談。理賠員先說公司決定賠一萬三千六百美元。Griffith 不爭辯，只問：你用什麼標準算的？哪裡買得到同樣的車？他自己找到類似的二手車一萬七千七百元，加稅約一萬九。理賠員加到一萬五，說「這是公司政策，已是上限」。Griffith 回：除非你能客觀說明這個數字，否則他寧可上法院，並約好週三再談。再談時理賠員拿出報紙廣告，同款車一萬四千八百元，Griffith 逐項追問：里程四萬九千對他的兩萬五千，值多少？科技配備呢？防眩目後視鏡呢？數字一項項加上去，半小時後他拿著一萬八千零二十四元的支票離開。

**作者用它說明：** 用可驗證的客觀基準，能拆解對方「公司政策」式的固定報價，改變結果。

**可比較的問題：** 以可驗基準拆解固定報價與授權話術

**個別界線：** 作者同事的案例，金額為書中敘述，未外驗或調整通膨。

**相關分類：** [客觀標準與公平程序](../standards_process/index.md)、[現有替代與議價](../batna_alternatives/index.md)、[決策權與必要支持](../decision_authority/index.md)

**相關名稱與說法：** Tom Griffith、company policy、18024、insurance、格里菲斯、車險

**出處：** 第 5 章〈Insist on Using Objective Criteria〉；〈Acknowledgments〉
