要改的是這張表：交接方案讓「好」變安全；珮君親口要人，讓「不」得給理由。

動線：先找誰、再找誰

  1. 1今明兩天｜你 → 珮君：確認三件事：缺是你的？到任可延？願不願意親口要人？
  2. 2同時｜你 → 人資：簽核何時要？月底有沒有彈性？
  3. 3拿到珮君的答案｜你 → 你的主管：交接方案換簽字
  4. 4第十天，若他仍不簽、講不出日期｜你 → 主管的上級：拿交接方案請他放人

珮君的答案決定第 3 步怎麼談，人資的答案決定月底是不是真的最後期限；第 3 步要的是月底前簽、交接完再到任。第 4 步收不回，交接方案提了、他還是不簽才走。
