# 地圖

## 文法

形狀可以換，這幾條不換：

- 位置帶有資訊：在哪一圈、靠近誰，就代表他對拍板的份量與關係；遠近與方位都有意義，不是為了排版。
- 節點只放名稱，人、職缺、房貸都可以是節點；判斷寫在線上與右欄。
- 兩種線：粗實線代表誰離不開誰，箭頭指向被依賴的人；細線代表話怎麼傳，箭頭指向聽話的人。
- 今天要動的那一條畫成藍色粗線，只能有一條。
- 推測或還沒發生的，用虛框、虛線。
- 拍板者旁放一張小表：列出他說好、說不，各自付出什麼。

形狀自由：有局就畫同心圓，拍板者在圓心；職涯決定畫你的位置圖（你靠誰、誰靠你、退路有多真）；都不合就畫別的，遵守同一套文法。

## 用模板畫同心圓

複製 `map-template.html`，只修改最上方 `map-data` 那段 JSON：

- `title`：標題。
- `people`：`name`、`ring`（1 拍板；2 他靠誰、少了誰不行；3 意見會被聽、定規則）、`guess`。同一圈照順序排，第二圈從正下方排起，外圈從正右方排起；你在哪一圈看這局，拍板者離不開你就放第二圈的第一個，不然放外圈。圈名可以照這局改，例如外圈改成「他沒見過、話靠人轉」。
- `lines`：`from`、`to`、`kind`（`depend` 從離不開的人指向被依賴的人；`talk` 從說的人指向聽的人）、`label`（用 `\n` 換行）、`guess`、`today`；雙向加 `both`。
- `choice`：`who`、`yesMeans`、`noMeans`、`yes`、`no`、`note`。
- `today`：接在今天那條線後面的一句話。

圖例由程式產生。存到工作目錄 `power-map/`，檔名用日期加題目摘要。有 `html_preview` 就用寬度 728 看一次，console 會說哪裡擠；有 `html_render` 就嵌進回覆。一個人若連了四條以上的線，標籤常沒位置放：先縮短標籤、用 `\n` 換行、把人換圈；還是擠就自己畫。

## 模板不合時自己畫

自己寫 SVG 或 HTML，遵守上面的文法：位置要有意義，節點只放名稱，今天要動的藍色粗線只有一條，小表和說明今天動哪條線的那句話，照樣放在圖旁。
