# 地圖

## 文法

形狀可以換，這幾條不換：

- 位置帶有資訊：在哪一圈、靠近誰，就代表他對拍板的份量與關係；遠近與方位都有意義，不是為了排版。
- 節點只放名稱，人、職缺、房貸都可以是節點；判斷寫在線上與右欄。
- 兩種線：粗實線代表誰離不開誰，箭頭指向被依賴的人；細線代表話怎麼傳，箭頭指向聽話的人。
- 動線：他要動的幾步畫成藍線，照先後在線上標號碼，最多四步，讀者光看圖就知道先找誰、再找誰、最後對誰出手。四步畫不下，只畫決定先後的那幾步，其餘寫進回覆。
  - 馬上做的（回覆寫今天、今明兩天這類）畫粗線、實心號碼，排在最前面。
  - 排定要做、排在後面的畫細線、空心號碼。內容要等前面問到的答案才定、又排在最後一步，也還是細實線。
  - 只有某個條件發生才走的備案或分岔，畫細虛線，標籤寫「若……」。拿不準就問：條件沒發生，這一步還做不做？還做，就不是虛線。
- 時間照回覆的字：回覆寫「今明兩天」「拿到答案後」「週五前」，圖旁清單就寫這幾個字，不改成「今天」或「之後」；回覆沒寫時間就不寫。
- 推測或還沒發生的局面，用虛框、虛線。動線本來就是還沒做的事，不因此畫虛線；動線畫成虛線，只表示有條件才走。
- 拍板者旁放一張小表：列出他說好、說不，各自付出什麼。

形狀自由：有局就畫同心圓，拍板者在圓心；職涯決定畫你的位置圖（你靠誰、誰靠你、退路有多真）；都不合就畫別的，遵守同一套文法。

## 用模板畫同心圓

複製 `map-template.html`，只修改最上方 `map-data` 那段 JSON：

- `title`：標題。
- `people`：`name`、`ring`（1 拍板；2 他靠誰、少了誰不行；3 意見會被聽、定規則）、`guess`。同一圈照順序排，第二圈從正下方排起，外圈從正右方排起；你在哪一圈看這局，拍板者離不開你就放第二圈的第一個，不然放外圈。圈名可以照這局改，例如外圈改成「他沒見過、話靠人轉」。
- `lines`：局面裡已有的線。`from`、`to`、`kind`（`depend` 從離不開的人指向被依賴的人；`talk` 從說的人指向聽的人）、`label`（用 `\n` 換行）、`guess`；雙向加 `both`。已經寫進 `moves` 的那一步，這裡不再畫一條。
- `moves`：動線，照先後排，第一筆就是 1 號。`from`、`to`、`label`（一行為主：帶什麼去、換什麼）、`when`（照抄回覆寫的時間，沒寫就省略）；馬上做的加 `now`，排在最前面；只有條件發生才走的加 `if` 寫條件，圖上會接成「若……」。
- `choice`：`who`、`yesMeans`、`noMeans`、`yes`、`no`、`note`。
- `order`：接在圖旁動線清單後面的一句話，說為什麼是這個順序。

圖例由程式產生。存到工作目錄 `power-map/`，檔名用日期加題目摘要。有 `html_preview` 就用寬度 728 看一次，console 會說哪裡擠、哪個號碼圈疊到東西，照它說的改到沒有警告再交，改不掉的在回覆裡說一句；有 `html_render` 就嵌進回覆。一個人若連了四條以上的線（動線也算），標籤常沒位置放：先縮短標籤、用 `\n` 換行、把人換圈；還是擠就自己畫。

## 模板不合時自己畫

自己寫 SVG 或 HTML，遵守上面的文法：位置要有意義，節點只放名稱，動線照先後標號、馬上做的一眼分得出來，小表和動線清單照樣放在圖旁。
