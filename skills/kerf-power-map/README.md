# Power Map

Power Map 是站在你這邊的職場軍師：用《Power》《Getting to Yes》《獨裁者手冊》的書中機制與案例，給你這一局能直接用的建議與開口說法，每輪附一張視覺化的權力地圖。

## 它做什麼

- 篇幅看你要拿去做什麼：要回信、代寫或寫書面說明，就給能直接寄出的稿和最多一個提醒；要整體打法或比較幾條路，才給完整策略（判斷與第一步、能用的稿、依據與退路）。第一步取決於你可能知道的事實時，同一輪最多問三題，並先給今天就能送的話。
- 分清原文記載、推論與未知：對方的動機只寫推測，沉默不算同意；不替你多答應加班、新期限或替別人背書，今天就能問的事不設門檻。
- 每條建議用一句話指回一個書中機制。隨附 99 筆有完整情節的書中故事（另有 712 筆一句摘要的案例索引），故事只在能分出兩個做法時出場，寫明和本案差在哪、因此選哪個做法。
- 照你下一步實際用的管道給稿：在信件或訊息串裡回就給全文，當面談就給開場白。
- 地圖先判卡點，再從六種圖型挑一種：疑慮對照、決策圈、傳遞路線、分支、立場四象限、利益交集。正文寫說什麼、做什麼，圖寫為什麼站得住、該選哪一步；短答配精簡圖，完整策略配一到兩塊面板。

先讀 skills/kerf-power-map/docs/install.md，依目前使用的 agent 選擇安裝路徑，
完成檢查後回報安裝路徑、來源 commit 及驗證結果。

Codex 的專案路徑是 `.agents/skills/kerf-power-map/`；Claude Code 是 `.claude/skills/kerf-power-map/`。不需要額外工具或模型。安裝完成後可直接描述你遇到的職場局面；Codex 也可用 `$kerf-power-map`，Claude Code 可用 `/kerf-power-map`。

## 已知限制

- 案例是依書中章節自行改寫的摘要，不是原文；書中沒寫的行動、結果與條件一律標為未知。要核對細節，請回到原書對應章節。
- 分析只根據你提供的資訊，看不到對方的想法與組織內情；建議裡的推測會標明，需要你實地查證。
- 推理強度會影響品質與速度：較低強度比較常替你多答應一件事，或把推測講成事實。重要的局面建議用最高強度，照念前自己再看一眼。2026-10-21 改版後的速度與錯誤率尚未重新量測；改版用的情境評測題組放在 repo 根目錄的 [evals/kerf-power-map](https://github.com/kerfnotes/skills/tree/main/evals/kerf-power-map)。
- 這是策略思考的輔助，不是法律、人資或心理諮商意見。涉及勞動權益、申訴或健康時，請找專業人士。
