# 套用到既有檔案

此流程只為指定圖表或圖片換樣式，沿用原文；整份 Office 文件自動重新設計不在此流程的承諾內。擷取結果是可讀內容與快取，不能用來完整往返重建文件。先複製原檔，在副本上修改；保留原檔與可編輯內容。先列出目標圖表與所在頁、段或工作表，再確認數字來源。可用來源依序核對原生圖表的「編輯資料」內嵌活頁簿、可存取的來源檔、同頁表格或 HTML 結構化資料。兩處數字不一致時，列出位置與差異，先釐清口徑，不自行選一組。只有點陣圖時保留原圖，列出重畫所需的類別、系列、數值、單位、期間與來源。重畫後逐一核對圖說與正文引用的數字。

先依[全交付字級索引](../design/README.md#全交付字級索引)選目標媒介預設與最終尺寸。Word／Excel 文字字級表只在使用者明確授權相應文字範圍且沒有原模板時採用；不據此擴張為全文重建。

先擷取 Office 檔中的可讀內容：

```sh
mkdir -p out
node scripts/extract.js 原始檔.pptx out/extract.json
# 也接受 .docx、.xlsx
```

`extract.json` 的圖表 `series` 來自檔內資料**快取**，保留類別、系列名、數值以及 `null` 缺值；它不保證與內嵌活頁簿的最新「編輯資料」一致。輸出中的 `unreadable` 是未解析或缺少的部分。不要把快取、圖上的標籤與正文當作三份獨立證據；若互相矛盾，回到來源檔與編輯資料核對。

## PowerPoint（.pptx）

保留文字框、表格、備忘稿與頁序，只換指定圖表。能用原生圖表時，修改其顏色與字型，保留 PowerPoint「編輯資料」能力；不要以圖片覆蓋可編輯圖表。使用 SVG 時，圖片框與 SVG 維持同一長寬比，附同尺寸 PNG 後備並填入描述圖意與關鍵數據的替代文字。`scripts/pptx.js` 的 `chart()` 已示範 `slide.addImage()` 嵌 SVG；同檔 `finish()` 會以 `scripts/png.js` 的 `svgToPng()` 更新後備 PNG。既有檔案若需改包裝，沿用這個 SVG／PNG 配對與 `asvg:svgBlip` 結構，不另建一套圖片格式。改完仍須在 PowerPoint 確認後備、替代文字與「編輯資料」。

## Word（.docx）

保留段落、標題、表格、頁首頁尾、圖說與交叉引用，只換目標圖片。以文件版面寬度產生 SVG，不照投影片寬度硬塞；圖說寫清楚單位、期間、來源。檢查分頁與圖說是否仍相鄰。

## Excel（.xlsx）

保留儲存格、公式與工作表。若圖表必須隨資料更新，改原生圖表的樣式並保留資料連結。嵌入的 SVG 只是當下快照，交付時寫明資料更動後須重產；不要用快照假裝動態圖表。

## HTML（.html）

保留語意文字、表格與錨點，把新 SVG 放回原圖表容器。檢查窄螢幕時容器和 SVG 的寬度設定，避免整頁橫向溢出；需要橫向檢視的表格可在自己的容器內捲動。

## 交付核對

說清楚改了哪些頁、段、工作表或容器；哪些內容維持原樣；每張圖的數據取自哪個原生資料、來源檔、表格或 HTML 結構；用哪種實際預覽檢查過。若某部分只靠快取、讀不到，或尚未用目標程式開檔確認，直接寫明。交付依 [四層證據](../SKILL.md#交付證據)分開回報程式核對、實際預覽、PowerPoint 原生編輯及讀者理解；不適用的層級標不適用。
