# 書中案例：從當下局面選擇閱讀方向

這裡收錄三本書的 712 筆案例／研究摘要：Power 283、Getting to Yes 160、獨裁者手冊 269。分類是閱讀入口；一個事件可以涉及多種機制，完整案例只保留一份，其他分類用連結指向同一頁。

從下方日常說法或機制分類找入口。每個分類開頭的「按問題選例」提供可比較的案例，後面保留按書排列的全部候選；入口案例只是閱讀起點，合適與否由本案條件決定。選例與類比方式見[案例使用指引](../cases.md)；[書籍資訊](sources.md)另列。

## 從日常說法找入口

| 當下的問題 | 先看哪裡；什麼差異會改變閱讀方向 |
|---|---|
| 都是我在補，功勞卻算別人的 | [貢獻與能力評價](performance_evaluation/index.md)：先分清實質增量；增量已清楚但主管沒看到，再看[能見度與聲譽](visibility_reputation/index.md)。 |
| 主管知道我做了什麼，卻沒列入考評 | [客觀標準與公平程序](standards_process/index.md)：看認列依據；標準已同意卻未落實，再看[承諾與履行](commitments_execution/index.md)。 |
| 做得很好，卻一直升不了或調不走 | [時機與位置](timing_position/index.md)：看職位與資源走向；若卡在現職少不了你，對照[資源與依賴](resources_dependence/index.md)。 |
| 對方說支持，事情卻不動 | [承諾與履行](commitments_execution/index.md)：看答應了什麼；若他無權決定或缺資源，轉看[決策權](decision_authority/index.md)或[資源與依賴](resources_dependence/index.md)。 |
| 對方一直反對，是不是針對我 | [資訊、溝通與認知](communication_perception/index.md)：比較理解差異；有明確利害衝突時看[利益與立場](interests_positions/index.md)，涉及被否定感時看[身分與面子](identity_face/index.md)。 |
| 想推跨部門方案，各方條件兜不攏 | [決策權與必要支持](decision_authority/index.md)：先找批准與執行者；再用[方案與交換](options_exchange/index.md)比較安排，若獎酬使人不願配合則看[制度與誘因](institutions_incentives/index.md)。 |
| 想找盟友、換主管，但不知道誰靠得住 | [聯盟與替換](coalitions_replacement/index.md)：區分不滿、支持與行動；同時用[現有替代與議價](batna_alternatives/index.md)檢查沒有盟友時的選擇。 |
| 談過還是沒用，要升級、暫停還是離開 | [阻力、升級與退場](conflict_escalation/index.md)：比較時機與代價；用[現有替代與議價](batna_alternatives/index.md)核對退路是否已能執行。 |

以上問法不預設原因。沒有吻合的入口，或需要另一種解釋時，從下方機制分類擴讀。
