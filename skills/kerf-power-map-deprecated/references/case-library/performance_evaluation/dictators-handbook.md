<a id="dictators-handbook-149"></a>
## 企業財務困難、董事核心與證券詐欺研究

案例編號：dictators-handbook-149。類型：書中研究轉述。

**人物／組織：** corporate executives、financially troubled firms

**書中情境與行動：** 書中報告大核心且財務困難企業的造假風險，以及薪酬低於申報績效的預警。

**故事：** 這不是單一事件，而是作者在討論公司治理與薪酬規範時，以「我們已累積相當證據」的口吻提到的研究發現。同樣有財務困難的公司，若所依賴的聯盟（需要取悅的支持者群體）較大，比聯盟較小的公司更可能發生證券詐欺。作者的解釋是：依賴大聯盟的主管，績效差時特別容易被撤換，面臨較高的去職風險，於是有誘因用不實報表掩蓋壞績效。書中還說，一個很好的企業詐欺早期警訊，是高階主管的薪酬比申報績效所預期的更低，而不是更高。書中未交代研究的樣本、期間與統計方法，只在註釋給出簡短出處。

**作者用它說明：** 作者認為，大聯盟下績效不佳的主管較容易被撤換，可能因而增加以不實報表掩蓋績效的誘因；因此規範公司行為應考慮治理規則的邏輯。

**可比較的問題：** 分析績效成果與任用、評價結果為何不一致

**相關分類：** [貢獻與能力評價](../performance_evaluation/index.md)、[制度與誘因](../institutions_incentives/index.md)、[承諾、驗收與履行](../commitments_execution/index.md)、[能見度與聲譽](../visibility_reputation/index.md)

**相關名稱與說法：** 企業財務困難、董事核心與證券詐欺研究、corporate executives、financially troubled firms、績效 評價、制度 誘因、承諾 執行、聲譽 可見度

**出處：** 〈Discretionary Money〉
