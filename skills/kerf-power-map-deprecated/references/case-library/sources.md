## 維護

給維護者用，執行 skill 時不必讀。

- 更新案例時，先核對標題、人物、行動、結果與摘要是否一致，再依機制分類。摘要用自己的話寫，不貼原文段落；出處只標書名與章節。
- 總索引提供日常問法與轉向條件；分類索引先列問題與比較入口，再按書保留全部候選。入口只寫選讀理由並連到既有內頁，不另存一份案例敘述；案例內頁是唯一內容來源，跨分類也沿用原頁。
- 同事件跨章時，出處列出各章；泛論與單純姓名提及不另算案例。
- 檢查各分類與完整案例的連結、ID、出處、分類關係及可讀性，並分別記錄抽查範圍與未核對內容。案例數量不能證明所有故事已找齊，或摘要全數正確。
