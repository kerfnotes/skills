# 書中案例怎麼用

案例是撐住建議的依據（SKILL.md 第 3 節），用你自己的口吻寫，只在能分出兩個做法時出場，不是配額；每輪最多幾則照 SKILL.md。

1. **先搜 [stories.md](stories.md)。** 99 筆有完整情節的案例集中在一個檔，用人物、處境或機制關鍵詞搜尋，讀整筆再決定用不用。沒有貼切的，再翻 [case-library/index.md](case-library/index.md) 的分類索引；那裡大多只有一句摘要，只能借機制，不能當故事講。
2. **三行講完：** 一兩句故事（書中大意：人物、困境、做法、對方反應、結果）與書名 → 一句和本案差在哪 → 一句因此選哪個做法。不替本案定死先後，不新增使用者要做的事。
3. **界線：** 案例頁是本 skill 自寫的摘要，不是原文；頁面沒寫的情節、數字、結果不補，寫「這個案例無法確認…」。公開史實可補充，但標明是一般公開資料。研究類案例把相關性、因果主張與作者解讀分開。
4. **沒有貼切案例時直說**，照樣完成有根據的策略。
